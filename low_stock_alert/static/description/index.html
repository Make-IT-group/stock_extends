Low Stock Alerts

Turn reordering rule thresholds into actionable, traceable alerts. Assign owners, exclude special cases, and notify users through activities, email, or both.

Know what needs attention before it becomes a shortage

The scheduled check reads the minimum and maximum values already configured in Odoo reordering rules. When current stock reaches or falls below the minimum, the module creates or updates an alert and follows the notification policy you defined.

📉

Threshold monitoring

Uses the minimum and maximum quantities from each reordering rule. No duplicate threshold configuration is required.

👤

Responsible rules

Route alerts by product, product category, or warehouse, with sequence-based priority and a global fallback.

🔔

Flexible notifications

Send an Odoo activity, an email, or both. Configure a resend interval for alerts that remain open.

🛡️

Controlled exceptions

Exclude products, categories, warehouses, locations, or individual reordering rules, optionally for a limited date range.

How it works

1. Read
The scheduled action reads active Odoo reordering rules.
2. Compare
Current stock is compared with the configured minimum.
3. Route
Exceptions and responsible rules determine what happens next.
4. Notify
The owner receives an activity, an email, or both.

Alert information at a glance

Operational context

Assigned user · Creation date · Product · Warehouse · Location · Current stock · Configured minimum · Configured maximum

Purchasing and follow-up

Last purchase · Purchase order · Vendor · Last purchase quantity · Times sent · Notification history · Related alerts

Configuration

  1. Open Inventory > Configuration > Settings and enable Low Stock Alerts.
  2. Choose the default notification channel and the automatic resend interval.
  3. Open Inventory > Reporting > Alerts > Responsibles and define who owns each alert scope.
  4. Use Exceptions for products or contexts that should not create alerts.
  5. The hourly scheduled action checks reordering rules automatically. It can also be executed manually for testing.
Resolution logic: when stock rises above the minimum, the current open alert is resolved automatically. If stock falls again later, a new alert is created and linked to earlier alerts for the same reordering rule.
